# Data and model assets

## Included

- Source code, configurations and experiment wrappers.
- 44 selected result CSVs and rendered method overview.
- Checksums for 30 retained checkpoints in [provenance/checkpoints.csv](../provenance/checkpoints.csv).

## External inputs

| Input | Source / protocol | Expected local placement |
| --- | --- | --- |
| ETH/UCY processed trajectories | [MID preprocessing](https://github.com/Gutianpei/MID); obtain underlying datasets under their provider terms | `models/processed_data_noise/<dataset>_<split>.pkl` |
| Stanford Drone Dataset | [Original dataset](https://cvgl.stanford.edu/projects/uav_data/) | Supply the annotation root to the SDD entry point |
| Controlled synthetic scenes | Generated by `sage/data/synthetic_navigation.py` | Generated at runtime |
| Trained models | Inventory retained locally; no hosted release asset is available yet | Paths in the checkpoint manifest |

The weight inventory records file identity, size and SHA-256. It does not provide a download URL. Reusing the paper's saved models requires the matching retained checkpoints or a new training run under the documented protocol.

Data, videos, processed pickles and weights are ignored by Git. The source repository includes no personal browser state, internal patent material, submission correspondence or historical runtime caches.

Known original machine storage prefixes in executable sources and CSV metadata are normalized to portable paths. Numerical result fields remain unchanged; [source_files.csv](../provenance/source_files.csv) records each transformed file's original and distributed hashes.
