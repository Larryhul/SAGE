# Experiment wrappers

Run wrappers from the repository root in Bash, or use the Python module commands in [reproduction](../docs/reproduction.md) from Bash or PowerShell.

`check_sage_*` verifies inputs; `train_sage_*` trains dataset-specific models; `eval_sage_*` evaluates saved models. Seed and scale wrappers preserve controlled experiment settings. Wrappers still require the inputs and weights listed in [assets](../docs/assets.md).
