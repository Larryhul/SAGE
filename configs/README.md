# Configuration index

Use `sage.yaml` for the ETH/UCY adapter, `sage_sdd.yaml` for SDD and `sage_synthetic.yaml` for controlled synthetic navigation. Additional configurations preserve homogeneous, decoupled, multi-robot and guidance comparisons. Select the configuration that matches the result's recorded protocol.

See [reproduction](../docs/reproduction.md) for commands and interpretation. Configure input paths for the current machine rather than relying on historical server locations.
