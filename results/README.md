# Selected results

This directory contains 44 retained CSVs. Numerical fields are unchanged; original machine-specific storage prefixes are replaced with portable aliases, recorded in [source provenance](../provenance/source_files.csv).

| Directory | Contents | Interpretation |
| --- | --- | --- |
| [benchmarks](benchmarks) | ETH/UCY, SDD, multi-robot and baseline comparisons | Main evaluations and important preceding controls |
| [ablations](ablations) | Decoupling, homogeneous encoding, roles, comfort and robot interactions | Mechanism checks and per-seed evidence |
| [guidance](guidance) | Guidance scale and objective weights | Trade-offs across controlled settings |
| [scalability](scalability) | Robot counts, runtime and social-force controls | Scaling protocol and seed statistics |
| [selection](selection) | Validation and candidate-epoch records | Model-selection evidence |
| [tables](tables) | Aggregated guidance and role tables | Compact summaries |

Use the [arXiv preprint](https://arxiv.org/abs/2607.16619) to identify the reported protocol. Selection records and prior controls are important intermediate evidence and retain that status.
